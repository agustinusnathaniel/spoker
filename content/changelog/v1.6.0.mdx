Manage multiple stories in a single session.

### New Features

- **Multi-story queue** — add, reorder, and swap stories in a queue so you can estimate multiple items without leaving the room
- **Task management** — edit or remove items from the queue, with the full list visible to all participants
- **Last voter indicator** — see who voted last so you know when it's time to reveal
